# Adventsfenster – Scherenschnitt-Vorlagen

28 schwarz-weiße Scherenschnitt-Motive für ein Adventsfenster (normales Küchenfenster).

- `Adventsfenster_Scherenschnitt_A4.pdf` – Übersicht, Anleitung und jedes Motiv auf 1 Blatt A4 (30 Seiten)
- `Adventsfenster_Scherenschnitt_Grossformat_2x2_A4.pdf` – jedes Motiv auf 2 × 2 Blatt A4, ca. 38 × 55 cm (114 Seiten)
- `Adventsfenster_SVG_Vorlagen.zip` / `svg/` – Vektordateien, verlustfrei skalierbar, für Schneidplotter (Cricut, Silhouette, Brother)
- `vorschau/` – PNG-Vorschau je Motiv, `Uebersicht_*.jpg` – Kontaktbögen

Beim Drucken „Tatsächliche Größe“ (100 %) wählen, nicht „An Seite anpassen“.
