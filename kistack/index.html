Install a KiCad skill pack

All three are open source on GitHub. Pick one, point your agent at a KiCad project, and ask it to review the board.

KiStack (American-Embedded)

Human-written skills for schematic work, PCB review, parts and BOM decisions, exports and Gerber review.

npx skills add American-Embedded/kistack

github.com/American-Embedded/KiStack

Ki-Stack (Milind220)

Teaches agents the native surfaces: kicad-python for live IPC, kicad-cli for render/export/DRC/ERC, kiutils-rs for offline file edits. MIT.

git clone https://github.com/Milind220/Ki-Stack
# then symlink skills/ki-stack/* into your agent's skills dir

github.com/Milind220/Ki-Stack

kicad-happy (aklofas)

Broadest scope: schematic analysis, layout review, EMC pre-compliance, SPICE, datasheets, sourcing, fab prep. Claude Code and Codex.

git clone https://github.com/aklofas/kicad-happy
# see README for the install step

github.com/aklofas/kicad-happy

Prerequisites for all of them: KiCad 8 or 9 with kicad-cli on your PATH, Python 3, and an agent CLI (Claude Code, Codex CLI or OpenCode).

What actually works today

Distilled from engineers' reports (EEVblog, Hackaday, GitHub issues). Use agents where they are strong and keep yourself in the loop everywhere else.

Reliable wins

  • BOM optimization: JLCPCB basic vs. extended parts, stock checks, alternates
  • DRC/ERC loops: run, read the report, fix the boring violations
  • Netlist and connectivity review against the datasheet
  • Footprint and symbol generation from existing library parts
  • Calculations: trace impedance, thermal, current capacity
  • Scripts: kicad-cli pipelines, export automation, panelization helpers

Still weak

  • Spatial judgment: agents cannot "see" a clean placement
  • Editing raw S-expression files without breaking ordering
  • Design intent: why a part sits where it sits is not in the netlist
  • Confident agreement with whatever framing you give the question
  • Running with permissions skipped: removes the human and degrades results
