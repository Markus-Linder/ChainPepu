What's inside

Fab profiles (5 fabs)

JLCPCB, PCBWay, OSH Park, Aisler, Eurocircuits. Standard 2-layer and 4-layer processes: track/space, via drill and annular ring, hole-to-copper, edge clearance, silkscreen minimums, board thicknesses, named stackups, assembly notes, file requirements. Every number carries its source URL and retrieval date.

KiCad rule files

One .kicad_dru per fab and process. Copy next to your project and DRC enforces the fab's minimums instead of KiCad's defaults. No more "it passed DRC but the fab rejected it".

5 board-class templates

Pre-filled DESIGN-CONSTRAINTS.md for 2-layer MCU, 4-layer MCU with USB 2.0 HS and RMII Ethernet, 2.4 GHz RF module, DC-DC power, and precision analog. Layer plans, signal groups with impedances and skew limits, placement rules, keep-outs, EMC rules.

kistack-review CLI

One command runs DRC, ERC and BOM export, compares your project's rules and net classes against the fab profile, and writes a Markdown report plus an agent prompt that triages findings and asks before touching placement.

Prompt library

Full review session, placement proposal (agent proposes, you place), net class setup from constraints, Gerber review, and respin diff between revisions.

Agent files

Extended CLAUDE.md / AGENTS.md with Claude Code, Codex CLI and OpenCode specifics, a session-start script, and a CHANGES.md template the agent appends to.

Questions

How accurate are the fab numbers?

They are copied from each fab's official capability page, with the URL and date next to every value. Fabs change capabilities, so each profile carries a retrieved date and the kit ships updates for 12 months. The licence says it, and we mean it: verify against the fab page before you order.

Does this replace a skill pack?

No. Install KiStack, Ki-Stack or kicad-happy for the KiCad know-how. This kit adds what those cannot know: your fab and your board.

Which KiCad versions?

KiCad 8 and 9. The rule files use the custom DRC rule syntax introduced in KiCad 6, and the CLI uses kicad-cli JSON reports from KiCad 8 onward.

Can I use it for client work?

Yes. Single-user licence covers any number of projects. Generated files (constraints, rules, reports) can be shared freely. Only the kit itself stays with you.
