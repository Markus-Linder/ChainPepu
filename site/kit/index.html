KiCad Agent Starter Kit

Four files that fix the three ways agents fail on real boards: they don't know your design intent, they edit without asking, and they agree with whatever you suggest.

One email with the download, then the weekly KiCad agent tooling letter. Unsubscribe any time. Prefer no email? Direct download.

What's in the zip

CLAUDE.md

Project instructions with hard rules: what the agent must ask before changing (placement, outline, stackup, parts, net classes) and what it may fix alone (silkscreen, values, overlaps). Works as AGENTS.md for Codex and OpenCode.

DESIGN-CONSTRAINTS.md

YAML design intent agents actually parse: rails and currents, signal groups with impedance, length and skew limits, fixed placements, keep-outs, thermal, EMC rules, BOM policy, open questions.

REVIEW-CHECKLIST.md

37 pre-fab items across schematic, electrical layout, mechanical/DFM and outputs. The agent reports each as pass, fail, cannot check or needs engineer, with evidence.

JLCPCB-BOM-WORKFLOW.md

Six-step prompt sequence: export, classify, fill LCSC numbers, basic-vs-extended swaps, stock and lifecycle check, apply approved changes only.

Install

cd my-board/
unzip ~/Downloads/kicad-agent-starter-kit.zip
cp CLAUDE.md AGENTS.md          # Codex CLI and OpenCode read this name
mkdir -p docs && mv REVIEW-CHECKLIST.md docs/
# fill the TODO lines in CLAUDE.md and DESIGN-CONSTRAINTS.md, then:
claude   # or codex / opencode
> Read CLAUDE.md and DESIGN-CONSTRAINTS.md, then run docs/REVIEW-CHECKLIST.md against this board. Do not edit anything yet.
